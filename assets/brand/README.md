# GearDrop brand assets

The mark combines a shopping bag with a navigation pointer. The brand system is monochrome:

- Ink: `#111211`
- Porcelain: `#F4F2ED`

The SVG files are the editable sources. The PNG files are platform exports used by the website and Expo app. App-store icons use a full square without transparency or pre-rounded corners; Android adaptive assets keep the mark inside the central safe area.

`geardrop-logo.svg` is the English lockup. `zhide-logo.svg` is the Simplified Chinese `值de` lockup. The registered app display name remains `值de` for `zh-Hans`.
