折扣数据如何产生

GearDrop 把品牌官网、官方 Outlet 和经销商公开页面中的商品事实标准化，但不会把一次抓取结果包装成永久有效的价格承诺。

内容更新: 2026-08-29
直接回答

每条商品记录至少保留品牌、商品名、销售平台、地区、币种、原始链接和更新时间；折扣率在原价大于现价时按 (原价－现价) ÷ 原价计算。购买前必须回到销售平台复核实时价格、库存与适用条件。

处理流程

  1. 读取公开来源
    按来源分批读取品牌官方 Outlet、公开商品页或经销商页面，不绕过登录、验证码或权限控制。
  2. 标准化商品事实
    统一品牌、商品名、品类、地区、币种、原价、现价、折扣率、尺码和来源标识。
  3. 运行质量门
    检查最低数量、更新时间、URL 生命周期、价格关系、图片和来源完整性；无法可靠确认的记录不应被包装成当前有效折扣。
  4. 发布并保留时间
    网页优先读取当前数据库，静态数据只作为降级；每条记录显示最近观察时间，并链接回销售平台。

折扣率定义

仅当原价和现价都为正数且原价大于现价时，GearDrop 才把差额表达为折扣。折扣率为四舍五入后的百分比，销售平台可能使用不同的舍入、会员价或促销口径。

不同国家或地区的商品不可只凭换算后的人民币数字直接比较，因为税费、运费、关税、退货成本和商品版本可能不同。

更新时间与新鲜度

自动任务按来源分批运行，通常每日多次。具体商品是否新鲜，以商品页显示的更新时间和原始销售页面为准，而不是以网站整体的宣传频率为准。

销售平台可能在两次观察之间改价、售罄、恢复库存或重定向 URL；GearDrop 的时间戳描述的是最近一次成功观察。

价格、库存与汇率限制

  • 页面展示的原币价格优先；人民币换算是固定参考汇率，不是支付报价。
  • 库存和尺码只在来源提供且解析成功时展示；缺失不等于有货或无货。
  • 税费、运费、会员资格、优惠码、区域配送限制和退货政策由销售平台决定。
  • 同名商品可能因年份、性别、颜色、尺码或区域不同而不是同一 SKU。
  • GearDrop 不以模糊名称强行合并无法可靠对应的商品。
若 GearDrop 与销售平台信息冲突，以销售平台结算页和政策为准；欢迎通过 Support 提供可复核的原始 URL 与时间。

商品索引与聚合页门槛

  • 商品 sitemap 只纳入折扣至少 45%、最近 14 天内成功观察、原始销售 URL 最近验证为 HTTP 200，且名称、价格、币种、图片和来源完整的活跃记录。
  • 未达到门槛的活跃商品仍可供用户查询，但规范商品页会输出 noindex,follow，不参与本轮重点索引。
  • 品牌和品类聚合页按品牌与标准化商品名合并地区报价，展示一条代表报价及覆盖地区/报价数量；它不宣称不同地区一定是完全相同的 SKU。
  • 进入 sitemap 只代表 GearDrop 建议抓取该页面，不代表 Google、Bing 或任何 AI 系统已经收录、引用或推荐。

机器可读与持续审计

这些文件改善发现、解析和审计能力，但不证明任何 AI 平台已经提及、引用或推荐 GearDrop。真实 AI 能见度必须在固定市场、语言、账号状态、查询面板和日期下独立测量。

目录状态快照 → 带时间戳的品牌、来源与地区覆盖汇总 目录状态 JSON → 同一快照的机器可读版本 llms.txt → 可选的站点发现与引用边界说明 Sitemap → 静态知识页与商品实体 URL 索引
